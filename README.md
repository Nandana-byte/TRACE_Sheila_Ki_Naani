# TRACE

## AI-Powered Collective Intelligence for Finding Missing People

> Every sighting is a clue. Every clue makes the search smarter.

TRACE is an intelligence layer that connects fragmented information from CCTV,
witness reports, photographs, social media, public transport and other sources.

Instead of treating every clue independently, TRACE combines evidence,
evaluates reliability and corroboration, reconstructs possible movement,
and prioritizes areas for search.

## Core Pipeline

Evidence Ingestion  
↓  
AI Evidence Analysis  
↓  
Evidence Fusion  
↓  
Evidence Graph  
↓  
Spatio-Temporal Reasoning  
↓  
Search Prioritization

## Target Users

- Police and investigators
- Search and rescue teams
- Verified volunteers
- Public witnesses
